# Maternal Health Risk Prediction in Kenya
### DSA 3900 — Final Year Project | USIU-Africa

**Student:** Selmah Tzindori Mise | ID: 602

## Project Overview
ML-based system predicting individual maternal health risk 
(Low/Moderate/High) for pregnant women in Kenya using 
KDHS 2022 data with Bayesian inference and AI API integration.

## Tech Stack
Python · TabNet · TabTransformer · XGBoost · CatBoost · 
PyMC · SHAP · Optuna · Streamlit

## Dataset
Kenya Demographic and Health Survey 2022 (KDHS 2022)
Source: DHS Program — dhsprogram.com
